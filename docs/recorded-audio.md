# أصوات مسجّلة مسبقاً (اختياري)

الموقع ينطق الألمانية بصوت المتصفح، وجودته تختلف من جهاز إلى آخر. هذه الوثيقة تشرح كيف تضيف **تسجيلات صوتية ثابتة** لنصوص تختارها، فيسمعها كل متعلّم بالصوت نفسه، مع بقاء صوت المتصفح لكل ما ليس له تسجيل.

> **الحالة الحالية:** البنية جاهزة ومختبَرة، لكن **لا توجد أي ملفات صوتية في المشروع**، والميزة **مطفأة** افتراضياً. لم يكن في بيئة العمل نموذج صوتي ألماني يمكن تحميله، فلم أولّد أي تسجيل. الصوت الذي ستولّده بنفسك هو الذي سيُستعمل.

## كيف تعمل

- الخدمة `RecordedSpeechService` (في `src/services/speech/`) تبحث عن نص الجملة في فهرس التسجيلات: إن وُجد شغّلت الملف، وإلا ترك الأمر لصوت المتصفح.
- يبقى صوت المتصفح في ثلاث حالات حتى لو وُجد تسجيل: إذا احتاجت الشاشة تتبّع الكلمة أثناء النطق (التسجيل لا يخبر بموضع الكلمة)، أو اختار المستخدم صوتاً بعينه، أو فشل تشغيل الملف. فلا صمت أبداً.
- لا يُحمَّل الفهرس ولا يُطلب أي ملف إلا إذا بُني الموقع بالمتغير `VITE_RECORDED_AUDIO=true`.
- الملفات الصوتية لا تدخل التخزين المسبق للتطبيق (قد تكون كبيرة)، وإنما يحفظها المتصفح عند أول تشغيل ليعمل الصوت دون اتصال بعدها.

## الخطوات

1. **اكتب قائمة النصوص المنطوقة:**

   ```bash
   node scripts/list-speech-texts.mjs
   ```

   تُكتب القائمة في `audio-work/speech-texts.json`: لكل نص حقل `id` (اسم الملف المطلوب) وحقل `text`. عند آخر تشغيل كان فيها **1535 نصاً (حوالي 72 ألف حرف)**: فقرات النصوص القرائية والنصوص كاملة، وأسطر المحادثات، وكلمات المفردات، وتسجيلات تدريب الامتحان، ونماذج الكتابة وجملها، والأزواج الصوتية، والكلمات المركّبة.

2. **ولّد ملفاً صوتياً لكل نص** بأي أداة تحوّل النص إلى كلام بصوت ألماني، واحفظه في `public/audio/de/<id>.mp3` (أو `.ogg` أو `.wav` أو `.m4a`). لا يلزم تسجيل الكل: ابدأ بما يهمّك (مثلاً نصوص A1 القرائية). اختيار الأداة والصوت لك، وتأكد من أن رخصة الصوت تسمح بإعادة نشر التسجيلات.

3. **ابنِ الفهرس** من الملفات الموجودة فعلاً:

   ```bash
   node scripts/build-audio-manifest.mjs
   ```

   يكتب `public/audio/manifest.json` ويطبع عدد التسجيلات الموجودة وعدد النصوص التي بقيت دونها.

4. **ابنِ الموقع بتفعيل الميزة:**

   ```bash
   VITE_RECORDED_AUDIO=true npm run build
   ```

## ملاحظات

- المفتاح هو نص الجملة بعد توحيد المسافات (`normalizeSpokenText`)، فإن غيّرتَ نصاً في المحتوى فسقط تسجيله وعاد صوت المتصفح حتى تعيد الخطوات 1 إلى 3.
- القائمة تغطي المواضع المذكورة أعلاه فقط. نصوص أخرى ينطقها الموقع (مثل جمل شرح القواعد وجمل الدروس) تبقى بصوت المتصفح ما لم تُضف إلى `scripts/list-speech-texts.mjs` بالصيغة نفسها التي تنطقها بها الشاشة.
- الفهرس يرفض أي مسار خارج مجلد الصوت أو يشير إلى موقع آخر، ولا يُشغَّل إلا ما اجتاز هذا الفحص.
